# CatCode Form Leads to CRM

Sends leads from your site forms to KeyCRM, SalesDrive, NetHunt, KeepinCRM and Telegram. No WooCommerce needed.

This repository mirrors the free version published on wordpress.org, version 1.0.2.

## Requirements

- WordPress 6.2+ (tested up to 7.1)
- PHP 7.4+

## Install

Install from the WordPress plugin directory (Plugins → Add New → search for the plugin name), or download this repository and upload it to `wp-content/plugins/catcode-form-leads-to-crm/`.
